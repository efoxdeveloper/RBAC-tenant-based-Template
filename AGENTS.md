# Project instructions

- Use Streamline Flex icons from https://www.shadcn.io/icons/streamline-flex for UI iconography throughout this project.
- Add icons as small, local React SVG components under `frontend/src/components/icons/`; do not introduce another icon library or use Material UI icons for new UI icons.
- Keep brand marks, such as Google's multicolor logo, as their official brand artwork.
- Follow the icon attribution guidance in `frontend/src/components/icons/ATTRIBUTION.md` when adding or updating Streamline icons.
